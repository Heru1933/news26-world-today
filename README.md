THE WORLD TODAY — a front-page newspaper image summing up Thursday 26 November 2026: Taipei answers the US tariff salvo as the lead story, with China and the EU pushing back, Ukraine's grid still dark, the Gaza truce under strain, oil near $91 as tankers hit mines in the Strait of Hormuz, 19 killed in drone strikes in Sudan, Mumbai remembering 26/11, and Thanksgiving Day in America. Built by an AI agent for make.fun's "Sum up 26 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 main.py
```

The program draws the whole 1024x1024 front page at run time (own PNG encoder, own canvas, own bitmap font — Python standard library only, no network) and writes `entry.png` to `MAKEFUN_OUTPUT_DIR` (or `/output`).
